# Customer-Churn-Analysis

## Project Overview
This project focuses on analyzing customer churn and understanding the factors that influence customer retention. Microsoft Excel was used for data analysis and MIS reporting, while Power BI was used to develop an interactive dashboard.

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Key Analysis Areas
- Customer churn trends
- Contract types
- Payment methods
- Customer service data
- Customer retention insights

## Project Files
- `Churn Data Consolidation.xlsx` – Excel data analysis and MIS reporting
- `Churn Dashboard.pbix` – Interactive Power BI dashboard
- `Customer_Churn_Analysis_Project (1).pdf` – Project report
- Dashboard screenshot – Visual preview of the dashboard

## Project Objective
To analyze customer churn patterns, identify important trends, and provide insights that can help businesses improve customer retention and make data-driven decisions.

## Skills Demonstrated
Excel, MIS Reporting, Data Analysis, Power BI, Dashboard Development, Data Visualization
